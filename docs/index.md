# Nextflow for HPC

These training materials include ready-to-use lessons and guidance for delivering a workshop on running reproducible and scalable scientific workflows with Nextflow on high-performance computing (HPC) systems.

Nextflow is a workflow orchestrator that supports portable, reproducible, and scalable analysis across different computational infrastructures. It integrates with HPC job schedulers, manages parallel task execution, and supports software containers for reproducible analysis.

The content of these pages is designed to help other trainers re-run and adapt Sydney Informatics Hub’s *Nextflow for HPC* workshop for their own learners. The workshop is intended for researchers and technical users who have basic Nextflow and command-line experience, access to an HPC system, and familiarity with job submission and containers.

It will help you to:

- Explain the structure and purpose of the *Nextflow for HPC* workshop
- Deliver the workshop using the provided materials
- Support learners in configuring and running scalable Nextflow workflows with appropriate queues, CPUs, memory, and walltime
- Explain how Nextflow workflow execution interacts with HPC job schedulers
- Support learners in managing containerised software environments and troubleshooting workflow errors
- Adapt the workshop to suit different audiences, formats, and HPC environments
